To use the script , download the event code 890169683 (event labs)
then put your driving settings on all assists
then hover over the start the race selection button and run the script, make sure after running the script u click back inside the forza 6 window
the script will auto click start and begin racing automatically, if it does not start moving right away when the race starts wait a minute or two it can take some time to start driving
when u want to stop, close the script and then just either exit the race if your in one, or just exit as normal if the race is over.
